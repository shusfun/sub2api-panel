# 0009 面板正式版编号与独立更新执行器

## 背景

面板的正式构建包含网页、`serve` 和 `issuer`。二进制升级涉及两个独立角色和面板数据库迁移。管理员需要从面板发起常规更新，部署侧继续持有迁移和进程控制权限。

## 决定

- 首版为 `0.1.0001`，Git 标签为 `v0.1.1`。末段四位，上限为 `9.99.9999`。常规发布末段只增一，前两段以及对应 Git 标签的变更必须由项目所有者明确指定。正式发布和生产切换需要项目所有者明确授权。
- 首个生产部署采用单机 Linux systemd。更新通过独立执行器协调 `serve`、`issuer` 和迁移，Unix socket 只对面板运行用户授权，面板管理员提交前执行 TOTP 二次验证。生产默认稳定发布频道。
- 下载使用面板仓库不可变 GitHub Release，版本清单、校验文件和目标安装包必须通过发布证明校验。清单声明可升级的来源版本、迁移模式和二进制回退条件。
- 短维护期间官方网关继续服务。面板数据库迁移使用独立角色，部署侧记录最新更新阶段和结果。数据库状态不明确时保留维护状态和备份，由运维恢复。

## 依据

主人确认了 Linux systemd、短维护窗口、首版与版本号上限，并明确要求 Git 标签的前两段也不得擅自变更。当前阶段准备并演练更新链路，正式发布由主人另行发出指令。
