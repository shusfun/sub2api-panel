面板改版原型

静态示意稿，数据全部是假的，不连接后端。确认方向后，再按这些样板改正式页面。

外壳与导航

侧栏只放工作对象，账户相关的入口收进右上角。

  • 管理员和普通用户两套侧栏
  • 折叠侧栏、账户菜单、告警铃、⌘K
  • 原版入口在新面板里的位置
  • 窄屏时用悬浮底栏

实时监控

状态页样板：首屏一句话回答“现在要不要管”。

  • “全站正常”和“1 项需要处理”两种状态
  • KPI 读数带和迷你趋势线
  • 压低一档的图表区

上游账号

集合页样板，其他列表页都按这个模式来。

  • 筛选栏和快捷筛选
  • 紧凑表格，行操作加“更多”菜单
  • 选中后浮起的批量栏，右侧检查器
  • 空态、加载、失败三种状态

下一批

样板确认后，按同一套规则出稿：

  • 站点设置（与账户设置拆开）
  • 上游规则（错误透传、TLS 指纹）
  • 订阅、渠道定价独立页
  • 推广返利、提示词审计

这一版的视觉规则

  • 外壳安静，结论醒目侧栏降一档：图标缩小、颜色变灰、可以折叠。颜色和大字只留给状态结论和异常数值。
  • 右上角位置固定⌘K、告警铃、账户菜单在每一页都在同一个位置，个人入口不占侧栏。
  • 页头只有一种写法标题，一行摘要，主操作固定在右边。摘要里直接写数字，例如“3 个需要处理”。
  • 用灰阶分层，少用边框沿用五档物理灰阶，不做卡片套卡片；KPI 是一条连续的读数带，不拆成五张卡片。
  • 操作不离开列表点行打开右侧检查器，勾选后批量栏从底部浮起；原版的弹窗长表单只留给新建。
  • 暗色往暖石墨调用上面的色板开关和现有暗色对比。
