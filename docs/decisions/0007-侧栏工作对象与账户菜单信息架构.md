# 0007 侧栏工作对象与账户菜单信息架构

## 背景
原版入口分散，个人项和管理项混在侧栏里，设置页同时承载个人和全站分区，订阅和渠道定价没有独立入口。暗色底色偏素，状态页缺少醒目的首屏结论。

## 决定
- **侧栏只放工作对象**。管理员分组为观测、号池、用户、系统；个人项（我的密钥、批量生图、购买与订单、模型广场、邀请返利、MCP 授权、站点公告、账户设置）收进右上角账户菜单。普通用户侧栏只保留我的密钥、用量分析、渠道健康、批量生图，模型广场与购买与订单按开关显示。
- **舱头右侧固定三样**：⌘K、告警铃（仅管理员）、账户菜单。侧栏底部身份区及样式删除。
- **侧栏降一档**，`[` 键折叠为图标栏（偏好键 `panel-rail-collapsed-v1`，不迁移旧值）；窄屏改为悬浮底栏。
- **路由**：新增 `subscriptions`、`channels`、`upstream-rules`、`affiliates`、`site-settings`；`/settings` 只渲染个人分区并改名“账户设置”，`/admin/settings` 渲染后端下发的站点分区加面板自有的“上游账本”。旧的混合布局直接删除，不留别名。
- **视觉**：暗色换成“琥珀点色”，琥珀只用于主按钮、焦点环、开关、侧栏当前项、品牌标、图表线和排行条，状态色调亮一档；平台色用 `--weir-plat-*` token，明暗两套。
- **状态页样板**：公共件 `Verdict`（一句大字结论，处理按钮在其下）和 `KpiStrip`（带迷你趋势线），用于实时监控和渠道健康。趋势线纵轴下限固定为 0（有负值取最小值）。

## 后果
- 管理员访问个人路径仍然可用，只是入口从侧栏移到账户菜单。
- 新增页面只需在 `route.ts`、`workspace.tsx` 和命令面板各登记一次。
